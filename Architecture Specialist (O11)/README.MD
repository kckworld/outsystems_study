## 준비

### 실무 교육 부트 캠프

- **기본 아키텍처 부트 캠프** 참석 권장
- **고급 개발자 부트 캠프** 참석 가능 (아키텍처 관련 2일 내용 포함, 실습 포함)

### 온라인 리소스

**지속 가능한 애플리케이션 설계 가이드 경로** — 특히 중요한 과정:

- 아키텍처 프레임워크를 사용하여 애플리케이션 설계
- OutSystems 아키텍처 패턴
- 스타일 가이드 아키텍처
- 애플리케이션 검증 및 재구성

**OutSystems 문서 — 권장 아티클:**

- OutSystems 애플리케이션 아키텍처 설계
- 핵심 서비스 추상화를 위한 통합 패턴
- 아키텍처 캔버스
- 비즈니스 개념을 애플리케이션 모듈로 번역
- 애플리케이션 아키텍처 검증
- 애플리케이션 구성
- 애플리케이션에 아키텍처 캔버스를 적용
- 애플리케이션 테마 격리
- 올바른 애플리케이션 구성의 4가지 규칙
- 아키텍처에서 개발로
- 기술 부채 관리 (문서) & 웹 및 모바일 아키텍처와 아키텍처 대시보드 (기술 토크)
- AI 멘토 스튜디오가 어떻게 작동하는가

## 등록

[OutSystems 인증 페이지](https://www.outsystems.com/certifications/)에서 시험 등록 가능.

1. 시험 찾기
2. 온라인 시험 또는 인증 시험 센터 선택
3. 시험 언어 선택
4. **'미리 등록'** 버튼 클릭
5. 데이터 입력 후 등록 단계 진행

## 시험 일정 변경

- 시험 예정일 **48시간 이전**까지 일정 변경 가능
- 48시간 미만 시 일정 변경 불가 (시험 응시 또는 기회 소멸)
- 원래 예정일로부터 **15일 이내** 변경 가능
- 원래 날짜로부터 **14일 이내** 변경 시 추가 요금 **$25 USD** 부과

## 시험 응시 방법

### 시험 센터

- 가장 완벽한 환경, 현지 언어 지원 가능
- 등록 시 가장 가까운 시험 센터 및 가능 날짜 확인 가능

### 온라인 시험

- 제3자 감독관(Prometric)이 감독
- 물리적/가상 환경 무결성 보장
- 자세한 내용은 [Prometric 사용자 가이드](https://www.prometric.com/) 참고
- ⚠️ **온라인 시험 감독 지원은 영어만 제공**

- 전문성은 특정 **OutSystems 버전**과 연결됨
- 이 시험 통과 시 **OutSystems 11**에 대한 아키텍처 전문성 취득
- 최신 버전 인증을 원할 경우 해당 버전 시험을 별도로 통과해야 함
